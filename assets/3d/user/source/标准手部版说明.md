# 标准手部版（当前默认）

文件：SignHuman_CleanHands.fbx、SignHuman_CleanHands.blend。原始 SignHuman_Final.fbx/blend 保留。

此版本保留用户人物的脸、服装与身体，替换原有问题手部。双手网格和蒙皮取自项目已在使用的 sample.vrm（动漫女性原版），每手 817 顶点。腕部与用户前臂对接，增加同骨骼过渡及肤色渐变。原先自动拟合的手部修复版仍在人物列表中作为对照。

## 当前程序的驱动

网页会加载不可见的动漫原版参考骨骼。相同动作先驱动原版，再根据导出时记录的坐标基准，将手掌和手指姿态转移给用户人物。参考骨骼不参与画面显示。此举避免仅靠手指方向重新猜测每个关节的扭转。

程序默认人物显示“我的数字人 · 标准手部版”。旧采集窗口需 Ctrl+R 或关闭后重开才会更新脚本。仅导出 FBX 并不包含网页参考驱动代码；其他引擎仍需对应的动作重定向设置。

## 验证

FBX 重新导入：70 骨骼，三块蒙皮网格，无零权重顶点或无效权重。

张手、握拳、指向和转腕四组测试中，双手“边长拉长超过静止状态三倍”的数量均为 0。指标只检查严重几何拉扯，不代表所有手势语义准确，也不代表没有自相交。

网页检查了同一动作的第 0、10、20、30、40、50 帧，与原版对照。离线检查页不会发送或接收直播字幕：

- 新形象：http://127.0.0.1:8877/output?model=SignHuman_Final&review=1
- 动漫原版：http://127.0.0.1:8877/output?model=sample&review=1

腕部接缝、皮肤细节和与脸部肤色的一致性仍可继续美化；这版优先保证指形与掌面姿态。字幕仍沿用实验性词动作拼接，未完成标准手语翻译。

详细资产参数见 clean-hands-report.json，FBX 检查见 clean-hands-verification.json。
