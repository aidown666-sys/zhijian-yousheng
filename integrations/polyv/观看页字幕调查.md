# 观看页字幕来源调查

调查时间：2026-10-24。频道：8662629。

## 已证实（官方网站当前发布的前端代码）

- 观看页 `https://10688df483.live.plvideo.net/watch/8662629` 返回 200。
- get-theme 返回 watchSdkEnabled=Y，加载 live-watch-v3/latest。
- 当前主 SDK 包：`https://s1.videocc.net/live-watch-v3/latest/assets/js/chunk-vendors.728a6e6d.js`。
- 字幕绑定：chat.getChatCore().onWs("subtitles", handler)。消息是 JSON 字符串。
- EVENT="ADD"：原声实时字幕；EVENT="TRANSLATE"：翻译字幕；EVENT="ENABLE"：开关。
- ADD 消息使用 text、replaceIndex、sliceType、index、language、relativeTime 字段。
- sliceType：0 开始，1 处理中，2 结束。只有 2 才适合进入完整句子动作队列。
- SDK 对 replaceIndex 的处理是按 JavaScript 字符串索引拼接：有 replaceIndex 且不超过当前临时文本长度时，text = old.substring(0, replaceIndex) + incoming.text；否则 text = incoming.text。
- 上层事件 SubtitleRealTimeCC 输出 text、sliceType、index、language。字幕模块默认延迟 1000ms。
- 字幕历史接口路径：/front/channel/subtitles/get，参数 roomId、index、size、order、token，经过 chatApi 签名。历史数据不能直接当成新字幕重播。
- chatToken 来自观看频道详情的 chatInfo.chatToken；观看 SDK 创建聊天连接时传入该 token、用户信息、频道号、场次信息。
- 默认聊天域名 chat.polyv.net；实际域名可被 domainInfo 配置覆盖。
- 当前 socket SDK：`https://websdk.videocc.net/socket/rc-20261015/index.umd.js`，含 Socket.IO 客户端，连接 query 带 token、version，默认 /socket.io 路径，优先 websocket、无 WebSocket 时 polling。
- Socket SDK 登录消息 EVENT=LOGIN，包括用户信息、channelId、roomId 和可选 sessionId。观看 SDK 同时兼容旧聊天 SDK，接入优先复用观看 SDK，避免误选底层协议版本。

## 尚未证实

此次浏览器工具读取直播页超时。以上是下载官方静态 HTML/JS 后得到的代码证据，尚未抓到当前直播的真实 WebSocket 字幕帧，不能宣称已经收到实时字幕或完成动作联调。

## 接入方向

本机以正常观看身份通过观看/聊天 SDK 接收 subtitles 事件，组装 Chinese 原声文字，sliceType=2 后按场次+index 去重，再提交本机 /api/captions。需要正常的观看授权、token 刷新、断线重连和切换场次处理。不需要 PHP 字幕文件回调作为实时字幕主通道。

该方案仍需实际消息验证，并处理词库缺词；成功收到任意字幕不等于能翻译任意中文为标准手语。
