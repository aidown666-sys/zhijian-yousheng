# 观看页实时字幕接入

运行 start.cmd，将优先读取 watch-config.json，自动启动 watch_bridge.py。当前配置频道 8662629。旧 PHP 桥接仍保留，但不会同时自动启动，避免重复字幕。

## chatToken

当前频道公开游客观看流程已实测：

1. GET /v3/common/channel/detail?channelId=8662629 检查观看方式为 none。
2. POST /v3/common/auth/none-auth/viewer/set-info?channelId=8662629，服务器返回 x-auth-token 观看会话。
3. GET /v3/common/channel/viewer?channelId=8662629&xSessdata=观看会话，返回 chatInfo.chatToken、viewerInfo 和场次信息。
4. 以 chatToken 连接聊天 WebSocket，Engine.IO 3 / Socket.IO；等待命名空间连接完成后发送正常 LOGIN 消息。
5. 订阅 subtitles，组装 Chinese ADD 消息，只在 sliceType=2 后提交本机 /api/captions。

chatToken 实测为 32 位不透明字符串，无 JWT 分段。外观不构成哈希生成算法的证据；实现不推导、不伪造凭据，断线后重新走正常游客授权。凭据仅在进程内存使用，不写入日志和浏览器前端。

## 支持范围

当前频道已验证聊天登录、真实中文字幕、定稿送入动作服务。有词库覆盖的短句能入队，缺词句子明确提示失败。

其他公开游客频道可通过修改 watch-config.json 的 watch_url 后重启 start.cmd 尝试。必须使用该频道实际的完整观看链接。需要登录、密码或付费授权的频道，当前实现会停止游客自动接入，不能保证任意直播间都能取得字幕。频道还需确实启用实时字幕。

这是依据当前官方观看页代码完成的研究接入，前端协议变化可能需要更新。当前仅适配默认聊天域名或 polyv.net 子域名。

## 状态与背景

控制台 http://127.0.0.1:8877/ ：实时显示接收数、动作入队数、缺词数。选择自定义背景图可本机保存并同步采集窗口，支持 cover/contain，最大 5MB，服务端会重新编码 JPEG、移除元数据，最大边长 4096。

诊断页 http://127.0.0.1:8877/diagnostics ：查看聊天登录、最近字幕、转换错误及输出窗口心跳。刷新已经打开的采集窗口以加载新版脚本。上传背景图不发送到保利威或其他云服务。

背景配置 runtime/background.json，重编码图片 runtime/background.jpg。移除背景会关闭图片显示；可以再次上传替换。
