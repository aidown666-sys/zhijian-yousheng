## 私有目录保护（先完成）

优先把 private/ 移到网站根目录之外，并在 PHP-FPM 环境中设置 `POLYV_SIGN_CONFIG` 为新 config.php 绝对路径，保证 open_basedir 允许该目录。state_dir 默认跟随 config.php 所在目录。

如果按包内默认结构保留 private/，必须给 Nginx 增加拒绝访问规则：

```nginx
location ^~ /polyv/tangjianguo/demo/shishizimu/private/ {
    return 404;
}
```

Apache 的 .htaccess 已随包提供。状态文件另有 PHP 退出前缀防护，但不能代替正确服务器配置。若反向代理未透传 Authorization，请在相应 PHP FastCGI 配置传递 `HTTP_AUTHORIZATION $http_authorization`。不要放宽 CORS 或把 consumer/producer token 写到网页。

## 服务器接口

- callback.php：保利威官方字幕生成回调，校验时间戳、MD5/SHA256（config 指定）、频道、中文和原声标记；只登记受限的官方 SRT URL。
- poll.php：本机以 Authorization Bearer consumer_token 拉取新增字幕；按游标、字幕时间段去重。
- ingest.php：预留给真正的逐句字幕生产者，使用独立 producer_token；格式见下文。它不是公开官方回调格式。
- configure.php：仅服务器命令行可运行，查询或设置回调；网页访问返回 404。
- private/config.php：服务端参数；private/relay-state.php：受保护的运行状态。

先在服务器终端执行（按实际 PHP 路径）：

```bash
cd /www/wwwroot/document.plvideo.net/polyv/tangjianguo/demo/shishizimu
php configure.php
```

确认新路径部署和私有目录防护正常后，再启用新回调：

```bash
php configure.php --enable-callback
```

此命令只更新字幕回调开关及地址，不更改实时字幕开关、语言或音频来源。若已有其他系统消费该回调，应先协调转发，避免覆盖现有用途。最终地址：

`https://document.plvideo.net/polyv/tangjianguo/demo/shishizimu/callback.php`

## 关键限制：字幕生成回调不等于逐句实时回调

官方文档中的回调返回 srtUrl，没有逐句 text/final 字段，也未承诺直播中逐句触发。脚本只能在得到 SRT 地址后每秒检查该文件的新增时间段。首次读取建立基线，**不把整段历史文件作为当前直播字幕播放**；若文件仅在直播结束后生成，或回调只在结束后发生，这条来源就无法实现实时驱动。

联调必须检查本机 `/api/bridge-status` 的 `last_callback` 和 `last_increment`：

1. 开播说出一句测试文本，观察直播中是否已收到 callback。
2. 继续说另一句，观察同一个 SRT 是否出现新增段落。
3. 只有观察到直播中连续新增字幕，才能确认该来源适用；不能以接口返回 200 判定实时闭环成功。

若该回调是归档性质，需要保利威提供直播字幕消息接口，或通过其观看 SDK 的字幕事件做采集适配后 POST ingest.php。当前包没有伪造或猜测该 SDK 实时事件协议，不能声称已实现此替代来源。收到真实逐句文本后，下游 PHP → 本机 → 3D 流程无需重写。

ingest.php 的项目协议（producer token 放 Authorization 请求头）：

```json
{"channelId":"8662629","id":"session-utterance-001","text":"今天我去学校","final":true}
```

## 本机启动

1. 双击项目根目录 start.cmd，保持服务运行。
2. 服务器上传配置完成后，双击 start-polyv-bridge.cmd；它使用 integrations/polyv/local-bridge.json 的 consumer token，只主动访问 HTTPS 服务器，不给电脑开放公网端口。
3. 打开控制台 http://127.0.0.1:8877/ 。桥接诊断： http://127.0.0.1:8877/api/bridge-status 。
4. 双击 open-capture-window.cmd，生成 Edge/Chrome 无地址栏应用窗口，标题为“指间有声 · 手语输出”。

首次连上桥接从最新位置开始，不播放历史。未成功送入本地服务则不推进游标；超过 15 秒的字幕丢弃，避免陈旧字幕持续积压。

## 保利威客户端采集

在客户端添加“窗口采集/共享窗口”（实际名称取决于客户端版本），选择“指间有声 · 手语输出”，裁去边框，缩放放入直播场景。保持窗口打开且不要最小化。该启动器不是虚拟摄像头，不会在“摄像头设备”里新增设备。

窗口默认纯绿底、不叠加字幕；若该版本支持色键/绿幕抠像，选取绿色并调阈值。普通窗口采集不会自动获得网页透明通道；若客户端没有色键，可改为纯色矩形布局，或通过 OBS 浏览器源合成后用虚拟摄像头接入。

独立输出参数：

`http://127.0.0.1:8877/output?bg=green&subtitles=0&model=ReferenceWoman_LocalRefined`

bg 支持 green / blue / white / black；不提供 bg 时网页保持透明（适合 OBS 浏览器源）。subtitles=1 显示字幕，0 隐藏。

## 转换能力

PHP 负责可靠地传递字幕；本机优先匹配整句动作，否则尝试 1,337 个词的动作拼接。**这不是任意中文到标准手语的翻译**：词序、非手部语法及未收录词仍未解决，缺词会提示并停止该句动作。直播主题词库、术语及句型转换需要后续扩展并由手语人员审核。当前动作资产沿用本地非商业研究范围。
